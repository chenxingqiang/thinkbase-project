\chapter{绪论}\label{ch:intro}

\section{研究背景与意义}
推荐系统是现代信息服务的核心基础设施：电商、内容平台与社交网络
均依赖个性化排序从海量候选中筛选用户可能感兴趣的内容。随着深度
学习的发展，序列推荐模型——从基于循环神经网络的
GRU4Rec~\cite{hidasi2016gru4rec}、基于自注意力的
SASRec~\cite{kang2018sasrec} 与 BERT4Rec~\cite{sun2019bert4rec}，
到图协同模型 NGCF~\cite{wang2019ngcf} 与对比学习方法
SimGCL~\cite{yu2022simgcl}——已能从用户历史交互中学习细粒度的
偏好表示。然而，监督信号的获取始终是推荐系统的结构性瓶颈：真实
交互数据稀疏、新物品/新用户冷启动严重、人工标注隐式反馈的代价
高昂。

与此同时，大语言模型领域出现了一类新的训练范式：\textbf{递归自
改进（Recursive Self-Improvement, RSI）}——模型\emph{自我生成}训
练数据、\emph{自我评估}数据质量、\emph{自我迭代}优化参数，形成
不依赖外部标注的闭环。代表性工作包括：Self-Refine~\cite%
{madaan2023selfrefine} 通过自我反馈迭代精炼输出；
STaR~\cite{zelikman2022star} 用模型自生成的推理路径构造监督信号；
Self-Improve~\cite{huang2023selfimprove} 以自一致性多数投票生成
高置信伪标注；Reflexion~\cite{shinn2023reflexion} 引入语言化自
我反思信号；Self-Rewarding~\cite{yuan2024selfrewarding} 与
SPIN~\cite{chen2024spin} 进一步将评判者与对手纳入自博弈闭环。这
些工作共同表明：一个足够强的模型可以充当自身的数据引擎。

将 RSI 范式迁移到推荐系统具有天然的吸引力：隐式反馈场景下"未观
测 $\neq$ 负样本"，模型对未观测交互的预测本身携带信息，自生成样
本相当于对模型知识的一种\emph{蒸馏回注}。对交互稀疏用户尤其如
此——冷启动与长尾场景正是监督信号最匮乏、自生成补充最可能产生
增益的位置（第四章的稀疏度分层分析将对这一直觉给出阴性检验结
果——假设的价值在于可证伪）。

但迁移的风险与吸引力同样突出。推荐场景缺乏语言场景的两类"安
全绳"：没有外部可验证器（无法用测试或规则判伪标签真伪），没
有独立的评估模型（生成者即评估者）。同时推荐数据的长尾结构提
供了偏差的温床——模型对头部物品的轻微高估，经自生成 $\to$ 训
练 $\to$ 再生成的回路会复利放大。因此本文的研究意义是双重的：
\emph{正面}，为推荐场景建立一套可量化、可审计的自生成数据准
入机制，使 RSI 从禁忌变为工程上可选的工具；\emph{反面}，给出
该范式的实证边界——在什么条件下它注定只是安全冗余。后者在
RSI 研究的文献版图中长期缺席，而本文将表明：边界本身与机制同
等重要，且给出边界的证据链同样构成贡献。

\subsection{推荐系统中 RSI 的机会与风险}
从信息论视角看，RSI 闭环的增益潜力有明确上界：自生成样本携带的
新信息不超过模型已有知识（参数中编码的分布）与真实交互分布之间
的互补部分。这给出两个推论。其一，\emph{收益位置}：收益集中在
"模型已知但未被充分利用"的区域——交互稀疏的用户（其偏好未被充
分训练）、长尾物品（其嵌入欠拟合）、以及正则化不足的决策边界。
其二，\emph{风险位置}：风险集中在"模型错得最自信"的区域——头
部偏好的自我复制、以及训练分布尾部的人为抹平。机会与风险在
空间上高度重叠，这正是 RSI 控制问题的微妙之处：不能因风险而
关闭整个闭环（放弃增益），也不能因机会而放任准入（引发崩塌）
——需要的是对自生成数据的\emph{外科手术式}准入控制。

从系统演化视角看，RSI 闭环还是一类新的训练算法设计模式：传统
训练算法的性能曲线由固定数据集决定，而 RSI 系统的性能曲线由
"数据—模型"共演化动力学决定。这使得评估协议本身需要变化——
单点评估（最终指标）不足以刻画系统，必须评估\emph{轨迹}（指标
随迭代轮次的形态：收敛、震荡、发散）。本文第 4 章的实验设计
（迭代曲线 + 漂移曲线 + 跨轮稳定性指标）正是对这一评估哲学的
落实。

然而，RSI 闭环并非免费午餐。自我生成的训练信号存在系统性风险：
模型倾向于强化自己已经相信的预测，而头部物品在预测分布中天然占
优，于是"生成—训练—再生成"的闭环会形成\textbf{头部自强化正反
馈}，随迭代轮次放大为分布漂移与性能崩塌；若再叠加对生成样本质量
缺乏量化控制，低置信样本的持续混入将造成误差累积。如何在推荐场
景中\emph{控制}自生成数据的保真度、使 RSI 闭环安全可控而非引发
崩塌，是本文研究的核心问题。

\section{研究背景的技术脉络}
推荐系统的输入天然是行为序列：用户的下一次消费偏好由其历史
交互的顺序模式塑造。这一观察驱动了序列推荐十余年的演进——从
马尔可夫链的转移概率估计，到循环神经网络对任意长度历史的编
码~\cite{hidasi2016gru4rec}，再到自注意力架构对全序列位置关系
的直接建模~\cite{kang2018sasrec,sun2019bert4rec}。监督信号始
终是同一份：观测到的交互本身。架构表达力在增长，训练数据的
信息量没有增长——精度竞赛在逼近数据携带的信息上界。

为突破监督稀缺，序列推荐引入两类补充信号：对比式自监督（视
图内一致性正则，如 SimGCL~\cite{yu2022simgcl}）与合成式数据增
强（扰动序列作为额外样本）。前者的信息来源仍是原始数据——
视图与合成样本都是已观测数据的变换，信息论上不含新内容；当
模型已充分拟合原始数据时，边际收益必然衰减，若生成过程存在
系统性偏差则收益为负。

RSI 将数据增强推到逻辑终点：模型用自己的预测生成下一轮训练
数据~\cite{madaan2023selfrefine,chen2024spin}。在 LLM 场景中
RSI 已展示可观增益，但其成功依赖两个推荐场景不具备的前提：
LLM 的生成器与评估器是两个模型，存在质量不对称可利用；且
LLM 评估（单元测试、格式校验）可低成本验证生成质量。推荐场
景中生成与评估共享同一模型——模型给自己的伪标签打分，验证
恰恰缺失。这是灾难的温床：头部物品的高置信预测被采为伪标签
，训练强化该预测，置信度进一步提高，正反馈闭环形成；第三章
将证明无干预条件下该闭环在数值上必然发散。

\section{国内外研究现状概述}
与本工作直接相关的三条文献线在第二章逐一展开，此处给出鸟瞰
式的定位。\textbf{序列推荐线}自 GRU4Rec 起经注意力架构到自监督
增强，方法持续精进，但训练数据始终限于观测交互——监督信号的
天花板问题在这条线内部无解。\textbf{自训练/半监督线}从 Yarowsky
的词义消歧到 FixMatch 的标准配置，积累了"置信筛选 + 扰动一致
性"的成熟工具箱，但其样本来源是无标注的真实数据，不含"自
生成分布风险"问题。\textbf{RSI 线}在语言模型上验证了递归自我
改进的可行性（Self-Refine、SPIN、Self-Rewarding 等），其成功
前提（外部可验证性、生成评估分离）在推荐场景结构性缺失。三
条线在"推荐的递归自改进"这一交叉点上的空白——如何为无验证
器的闭环构建分布安全机制——正是本文的立足点：以自训练的工
具箱为部件、以 RSI 的闭环为骨架、以推荐场景的流行度结构为
控制接口。国内研究在序列推荐与去偏方向活跃（相关代表工作见
第二章），RSI 视角的推荐自训练研究尚属起步，本文愿为该方向
提供第一个带完整阴性/阳性证据的机制研究样本。

\section{研究问题}\label{sec:questions}
在上述背景下，本文把研究任务陈述为三个递进的问题：
\textbf{RQ1（现象）}在序列推荐场景，朴素 RSI 闭环是否必然退化
？退化的机制路径是什么？
\textbf{RQ2（机制）}什么样的保真度控制能把退化转为受控过程
？控制效应如何分解到各设计轴？
\textbf{RQ3（边界）}受控 RSI 的净增益空间在哪里？哪些场景下
它有正的期望收益，哪些场景下它只是安全冗余？
三个问题的答案结构对应论文的贡献结构：RQ1 由崩塌复现与归因
回答；RQ2 由机制网格的完整交叉回答；RQ3 由诚实边界分析、稀
疏度分层与适用域论证回答——其中 RQ3 的答案部分为阴性，本文
将其视为与阳性同等的一等结果。


本文聚焦 RSI 闭环在序列推荐中的两个具体缺陷：

\begin{description}
\item[Q1 自生成数据分布漂移。] 模型自生成样本天然偏向其头部预
测，随迭代轮次训练分布持续偏离真实交互分布；这一漂移能否被量化
度量并在训练过程中被在线控制？
\item[Q2 迭代误差累积与崩塌。] 朴素自训练闭环为何崩塌、崩塌的动
力学是什么；何种生成与准入机制能将崩塌转化为稳定甚至正向的迭代
轨迹？
\end{description}

\section{研究内容与创新点}
针对上述问题，本文提出\textbf{保真度门控的递归自改进序列推荐框
架}，创新点如下：

\begin{enumerate}
\item \textbf{RSI 闭环的形式化与失败模式复现}（第
\ref{ch:framework} 章）：将 RSI 闭环形式化为五段迭代过程，给出分
布漂移与误差累积的度量；在 MovieLens-100K 上复现朴素自训练的崩
塌（NDCG@10 由 \ExpNaiveStart{} 崩塌至 \ExpNaiveEnd{}），并实证
其头部自强化根源。
\item \textbf{分层校准的保真度门控机制}：置信轴按流行度分层对预
测裕度做 z 标准化（实测保护的主要来源之一）；分布轴以分层 JS
距离预算约束混合分布漂移，作为候选池退化时才接管的条件性安全
网（第 4 章机制网格如实报告其在本数据集上从未咬合、净效应为
零，其约束力由单元级构造测试验证）。
\item \textbf{多视图一致性伪标签生成}：以 $K$ 个扰动视图上预测的
一致性为生成条件，使自生成样本编码扰动鲁棒信念而非头部偏好，为
闭环提供非自强化的信息来源。
\item \textbf{可复现实验基础设施}：全部实验以固定种子、单线程确
定性的方式实现，并以指令流编排（生成—门控—混合—重训—评估的
每轮各为一条可审计指令），实验结果可由命令行逐字节复现。
\end{enumerate}

四项创新点的证据状态应如实区分。第一项（形式化与复现）的证
据最完备——崩塌在全部种子与轮次上一致，机制归因（层分布测
量）直接可观测；第二项（门控机制）的证据有明确的边界条件——
置信轴的保护效应经配对检验显著，分布轴在本文配置空间内实测
净效应为零，其安全网价值属于设计层断言；第三项（一致性生成
器）的相对优势在机制网格中稳定（同为双轴门控下显著优于
top-$k$ 生成），但其绝对收益仍受"自生成数据无新信息"的全局
上界约束；第四项（基础设施）不依赖实验结论，其正确性由单元
测试与逐位复现验证本身保证。本文不声称任何超出上述证据的贡
献——特别是，\emph{不}声称 RSI 在本设定下带来净性能增益；框
架的价值主张是过程安全与机制可归因。

\section{论文组织结构}
全文按"问题—机制—证据—反思"的主线组织。第一章陈述研究问题
与技术脉络；第二章从三条文献线（序列推荐、自监督、RSI/自训练
）汇出"评估环节缺失"的领域空白与本文的位置；第三章形式化闭
环、证明朴素方案的崩塌倾向，并给出框架的组件设计与备选决策
记录；第四章以预注册协议完成主对比、机制网格、敏感性与适用
域四组检验，阴性结果同等成文；第五章总结贡献、反思方法论的
可迁移教训并给出分层展望。附录给出门控算法伪代码与完整复现
声明。各章的关系是递进的证据链：第三章的每个设计决策在第四
章都有对应的受控检验（生成器 $\to$ 机制网格生成器轴；置信轴
$\to$ 门控轴；预算 $\to$ 不咬合发现的如实报告），设计不自证、
由数据裁决。
